# Gate standard

Every governance gate presented to the operator must satisfy these rules.

1. Panel before human. An independent multi-lens review panel runs and passes BEFORE any artefact reaches the operator. Panel verdicts are independent — never self-authored by the doer whose work is under review.
2. Plain-English, content-contract-driven. The gate is presented from an authored <!-- gate:contract --> block (plain-English SECTION prose + any DECISION lines), not a raw document dump.
3. Fail-closed presentation. A gate with no valid content contract degrades to a FLAGGED / blocked state, never a silent raw dump.
4. Actionable. The operator decides (Accept / Amend / Decline) from the presented surface; the decision drives the audit record.
